# Actual browser PDF visual evidence

Exact original PDF and PNG hashes, amounts, row counts and scope are recorded in [the review manifest](../browser-pdf-visual-review.json). Original PDFs are retained in `../browser-compiled/`.

This evidence is separate from the twelve bilingual saved-template specimens. It proves the listed actual exported pages, not a production rollout or approval of legal wording.
